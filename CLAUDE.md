# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project overview

ACE (Agentic Context Engineering) is a research implementation of a framework where LLMs
self-improve by evolving a "playbook" (structured context) through a Generator / Reflector /
Curator loop, instead of fine-tuning weights. Fork of `ace-agent/ace` (arXiv:2510.04618).

- `ace/core/` — `generator.py`, `reflector.py`, `curator.py`, `bulletpoint_analyzer.py` (the core loop)
- `ace/prompts/` — prompt templates matching each core module
- `eval/<task>/` — one dir per benchmark (`finance`, `mbpp_code_exec`, `mind2web`, `mind2web2`), each
  with its own `run.py` and `data_processor.py`
- `llm.py`, `utils.py`, `logger.py`, `playbook_utils.py` — shared infra (LLM client setup, logging,
  playbook parsing) at repo root
- `ace-appworld/` is a git submodule and is currently uninitialized/not in use — ignore it unless
  specifically asked to work on AppWorld evals

## Setup and running

Package manager is **uv** (`uv sync` to install). Python 3.12 is pinned in `.python-version`, though
`pyproject.toml` allows `>=3.10`.

Run an eval as a module, e.g.:
```
uv run python -m eval.mbpp_code_exec.run --task_name finer --mode offline --save_path results
```
Modes: `offline`, `online`, `eval_only` (pass `--initial_playbook_path` for eval_only).

There is no test suite. Verify changes by running the relevant `eval/<task>/run.py` against a small
sample and checking the output.

## Gotchas

- **LLM backend is hardcoded to a personal tunnel.** `utils.py::initialize_clients()` ignores the
  usual meaning of `--api_provider` and always builds OpenAI-SDK clients pointed at
  `https://ollama.caduceus.lol/v1` with an empty API key and a `bypass: true` header. This is the
  current, expected dev setup (not a bug to "fix") — it will only work with access to that tunnel.
- **`eval/mbpp_code_exec` requires a running Docker daemon** — it pulls `python:3.10-slim` to sandbox
  code generated by the LLM.
- Lint with `uv run ruff check .` (config in `ruff.toml`). The repo has ~170 pre-existing
  findings — don't mass-fix them incidentally; only clean up lines you're already touching.

## Git workflow

Commit directly to `main` — this is a solo research repo, no PR ceremony needed.
